# Contrato

## Comandos públicos
| Comando | Descripción |
| --- | --- |
| `bun run verify` | Verifica el repositorio |
| `bun run build:target` | Compila el binario |
| `forge614-demo check` | Revisa un repositorio |

## Códigos de error
| Código | Significado |
| --- | --- |
| `INVALID_ARGUMENTS` | Entrada inválida |
| `DEMO_FAILED` | Falló la demostración |
