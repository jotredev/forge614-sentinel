# Forge614 Sentinel (`forge614-sentinel`)

> Analogía en una frase: como un inspector municipal, llega con el reglamento vigente, revisa el edificio, entrega el acta y se va; no construye ni repara.

## Qué es
El verificador del ecosistema Forge614: revisa un repositorio contra el Estándar de Nodo que declara y entrega un informe con veredicto y evidencias.

## Qué no es
- No corrige ni escribe en el repositorio que revisa.
- No elige el reglamento por su cuenta: usa la versión que el repositorio declara.
- No revisa proyectos de terceros ni ejecuta el nodo.

## Instalación

macOS / Linux:
```bash
curl -fsSL https://github.com/jotredev/forge614-sentinel/releases/latest/download/install.sh | bash
```

Windows (PowerShell):
```powershell
irm https://github.com/jotredev/forge614-sentinel/releases/latest/download/install.ps1 | iex
```
